# Support

Start with the [README](README.md) and the documents in [`docs/`](docs/).

- For a reproducible bug, use the bug report template.
- For a product idea, use the feature request template.
- For a security problem, follow [SECURITY.md](SECURITY.md) instead of opening a
  public issue.

Include your browser version, source image format, approximate dimensions, and
the exact tool or export setting involved. Use a synthetic image that can be
shared publicly.
